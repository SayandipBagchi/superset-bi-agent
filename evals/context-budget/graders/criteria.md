# Criteria: context-budget

Score each item independently. An item that cannot be checked from the output is a fail, not a pass.

- [ ] Answers only the mandate set-up question that was asked
- [ ] Names the repayments journey as the one it is working from
- [ ] Does not enumerate onboarding funnel content: applications, KYC, bank connection or decisioning stages
- [ ] Does not enumerate app sign-up content: sign-in, activation or first-spend cohorts
- [ ] Does not enumerate transaction content: spend, authorisations, RFM or the decline taxonomy
- [ ] Does not enumerate concentration content unless the mandate answer itself produces an event count
- [ ] States which tenant file section it needs (the repayments journey section) rather than reading or reciting the whole tenant file
- [ ] Asks which provider or PSP handles the mandate rather than assuming a rail
- [ ] Names provider authorisation page abandonment and mandates stuck at initiation as in scope
- [ ] Does not restate the full Phase 0 to 9 loop or produce a storyboard for a question that asked for neither
- [ ] Quotes no mandate conversion rate or stage count as a fact without saying it has to be queried
